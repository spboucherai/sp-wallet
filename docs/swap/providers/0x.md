# 0x Swap API v2 — provider dossier

Read in the official documentation on **2026-11-15**. Adapter: `packages/swap/src/providers/zerox.ts`, provider id `zerox`
(price comparison only, `executability: quote_only`, code `comparison_only`).

**Nothing below was checked against the live API.** 0x requires an API key on every call and none was available: the adapter
is written from the documented request and response, and its tests replay **documentation-derived fixtures**
(`packages/swap/test/fixtures/zerox/`, each file says which values come from the documentation's example and which are
constructed). The only live fact is the one recorded by the V11 audit: a call without a key answers `401`
("No API key found in request").

## API

| | |
|---|---|
| Base | `https://api.0x.org` |
| Key | **Required**: "Every 0x API call requires an API key." Header `0x-api-key: <key>` (0x Dashboard) |
| Version | Header `0x-version: v2` |
| Indicative price (used) | `GET /swap/allowance-holder/price?chainId&sellToken&buyToken&sellAmount[&taker][&slippagePpm]` |
| Firm quote (never called) | `GET /swap/allowance-holder/quote` — same parameters, `taker` required, returns `transaction.{to,data,value,gas}` |
| Permit2 variant (not used) | `/swap/permit2/price`, `/swap/permit2/quote` — adds an off-chain Permit2 signature; AllowanceHolder is the simpler path for a wallet |

Parameters the adapter sends: `chainId`, `sellToken`, `buyToken`, `sellAmount` (base units, decimal string) and
`slippagePpm` = the owner's tolerance in basis points × 100. The reference marks `slippageBps` (default 100) as deprecated in
favour of `slippagePpm`; the two are mutually exclusive. **Not sent**: `taker` (optional for a price — an indicative price
should not disclose the wallet's address to a third party), any fee parameter (`swapFeeRecipient`, `swapFeeBps`, …),
`excludedSources`.

Wallet networks served — each is in 0x's "Swap API supported chains" table, with the same chain id as the wallet registry
(asserted by a test):

| wallet id | chain id | | wallet id | chain id |
|---|---|---|---|---|
| ethereum | 1 | | optimism | 10 |
| base | 8453 | | bsc | 56 |
| arbitrum | 42161 | | avalanche | 43114 |
| polygon | 137 | | hyperevm | 999 |

0x also lists Abstract, Arc, Berachain, Elysium, Ink, Linea, Mantle, Monad, Plasma, Robinhood, Scroll, Sonic, Tempo, Unichain and
World Chain: none is a wallet network.

Conventions:
- **Native coin**: `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE` as `sellToken` / `buyToken`.
- **Amounts**: decimal strings in base units. `buyAmount` → `amountOut`; `minBuyAmount` → `minAmountOut` — 0x's own minimum for the
  tolerance sent ("the transaction reverts below this"); it is used as given, never recomputed.
- **No liquidity**: HTTP 200 with only `{ liquidityAvailable: false, zid }` → no route.
- **Network fee**: `totalNetworkFee` (wei, nullable) → fee `network` in the native coin, `estimated`, not included in the output.
  When it is null no network fee is reported (`gas` × `gasPrice` is not substituted for it).
- **0x's fee**: `fees.zeroExFee` `{ amount, token, type: "volume" }` (nullable) → fee `provider` in the token it names, which must be
  one side of the pair. Reported as **already included** in the output: the reference defines `buyAmount` as the amount of
  buyToken "to receive". **Not verified live** — if `buyAmount` turned out to be gross of that fee, the comparison would flatter
  0x by the fee; the card shows the fee line so the figure is never hidden.
- **Integrator fee**: `fees.integratorFee` / `integratorFees` must be null — none is requested; an answer carrying one is refused.
- **Gas fee**: `fees.gasFee` (type `gas`, gasless flows) is mapped like a network fee paid in a token, included in the output.
- **Price impact / duration**: the price answer has neither → `priceImpactBps: null`, `estimatedSeconds: null`.
- **Validity**: no expiry field. The adapter keeps a price 15 s (`expiresAt = now + 15 s`) — the wallet's choice, not 0x's.
- **Route**: `route.fills[].source` → the venues shown; `route.tokens` kept in `raw`.
- **Token taxes**: `tokenMetadata.{buyToken,sellToken}.{buyTaxBps,sellTaxBps,transferTaxBps}` are kept in `raw`, not interpreted.
- **Errors**: `{ name, message, data }` (the reference gives type definitions, not literal examples). `400 TOKEN_NOT_SUPPORTED`,
  `422 BUY_TOKEN_NOT_AUTHORIZED_FOR_TRADE` / `SELL_TOKEN_NOT_AUTHORIZED_FOR_TRADE` → no route. Everything else
  (`INPUT_INVALID`, `SWAP_VALIDATION_FAILED`, 401, 403, 5xx) is a provider failure; 429 → `rate_limited`.

## Why it is comparison only
What 0x returns for execution (`/quote`) is a transaction whose `to` is a **Settler** contract, or AllowanceHolder `exec`
wrapping a Settler call. Settler is redeployed over time (0x publishes a registry), so the model used for KyberSwap — one
pinned router address and bytecode hash — does not hold. The token approval goes to **AllowanceHolder**
(`0x0000000000001fF3684f28c67538d4D072C22734` on the Cancun-hardfork chains, which covers the eight networks above;
`0x0000000000005E88410CcDFaDe4a5EfaE4b49562` on Mantle), never to the transaction target.

For execution the isolated signer would need: AllowanceHolder pinned per chain, a reviewed set of Settler code hashes per
chain, and a decoder of Settler's `execute(slippage, actions, …)` proving recipient, buy token and minimum amount
(`slippage` carries them). None of that exists. The wallet therefore never calls `/quote`, builds nothing and signs nothing
from a 0x answer; the UI labels the route "comparison only" and the API refuses its reference at preparation
(`quote_not_executable`).

## Status, tracking, refunds
Not applicable (no execution). For the record: a 0x swap is one transaction that settles in full or reverts.

## Fees
0x charges a volume fee on some pairs and plans, reported in `fees.zeroExFee`. The adapter requests no integrator fee and
refuses an answer that carries one.

## Key, rate limits, terms
- The key lives in the API process environment (`ZEROX_API_KEY`), on the node that serves the web app; it never reaches the signer.
  Without it the provider is listed as `needsKey` in `GET /api/v1/swap/providers` and is never asked.
- **Rate limit**: the documentation read states no figure for the free tier (it is shown in the dashboard). The adapter's policy
  is a deliberately low 1 request/s, burst 2 (`packages/swap/src/enabled.ts`); raise it only after reading the plan's limit.
- **Terms of use were not reviewed.** deBridge is off by default because its licence forbids "aggregation purposes"; 0x's terms
  must be read for the same kind of clause before a key is configured. Configuring the key is the owner's opt-in.
- Privacy: every price request tells 0x which pairs and amounts are being looked at, tied to the key's account. No address is sent.
