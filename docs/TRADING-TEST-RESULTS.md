# Trading agents and trading API (V11.1 / V11.2) — test results

The V11.1 verification list, line by line: for each, the test that covers it, the level of evidence, and what is not
covered. Compiled from the work notes (`docs/v11/work/agents.md`, `agents-bind.md`, `exec.md`, `exec2.md`,
`trading-api.md`, `sdks.md`, `contract-resync.md`, `quotes.md`, `quant-lab.md`, `mm-core.md`); counts and results are as
reported there. No suite was run to write this page. The module-level tables and the full-suite totals are in
`V11-TEST-RESULTS.md`.

**No line of this list was exercised with a real order.** "Signed" always means: signed by the real signer code, in a
test process, with a public test mnemonic, for a scripted venue that is not the venue. The test environment of this
project is that one; the Hyperliquid testnet was not used by any V11 workstream.

Levels: **U** unit · **I** real local server + PostgreSQL · **S** real signer code, fake venue · **R** recorded real
market data · **L** live public market data (read-only) · **B** real browser (Chromium, local dev stack).

Test files are under `services/api/test/` unless a path is given.

## 2. Not covered by any test

- Anything on a funded account, testnet included.
- The live approval flows in a browser (trading mandate, two prompts; resume / re-base; GMX limits — no UI).
- Stream agents with a recorded (not scripted) second venue; dYdX / GMX polling under a stream agent.
- `halted` and `restricted` on a perp agent's paper start; `halted: null` on balances.
- The separate agents worker under PM2 / mld; a production restart; a soak.
- Safari / iOS for the stream and every new screen.
- The command path on GMX; the GMX key refusal over HTTP; attached SL/TP on the live path.
- The migration of an engaged agents-side kill-switch flag on a real pre-V11.2 database.
- A real successful swap proposal through the order service's in-process port.

## 3. Results that are evidence against enabling something

| Result | Source |
|---|---|
| Seven strategies, 180 days of real data, V11 costs and engine limits: **no out-of-sample edge**; deflated Sharpe 0.000 – 0.099 (0.95 needed); four stopped by the engine's loss limits in at least one split | `quant-lab.md` §3 |
| End-to-end transcript of the live-capable momentum strategy: test-split net return −0.88 %, net Sharpe −1.43; costs 19.7 × gross profit | `agents-bind.md` transcript |
| Market-making study and simulator: negative PnL, adverse markouts at 1 s, 10 s and 60 s, maker fee paid | `docs/V11-MARKET-MAKING.md` §10 |
| Cross-exchange study: the entry edge never covers the exit on near-simultaneous recorded quotes | `quant-lab.md` §3 |
